
## Presentation sources

- Vercel rewrites: https://vercel.com/docs/routing/rewrites — external rewrites forward requests to another origin without changing the browser URL; supports API proxying and combining services.
- Vercel deployments: https://vercel.com/docs/deployments — Git pushes to a connected repository can trigger deployments; Production is the user-facing environment.
- Supabase Storage buckets: https://supabase.com/docs/guides/storage/buckets/fundamentals — private buckets are access-controlled and support upload restrictions; signed URLs are an access method.
- Supabase private asset downloads: https://supabase.com/docs/guides/storage/serving/downloads — private assets are not public URLs and can be served through time-limited signed URLs.
